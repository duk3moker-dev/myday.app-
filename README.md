# MyDay

**Versão 0.1.0 — primeira base funcional.**

MyDay é um planejador pessoal mobile-first, criado inicialmente como PWA simples.

## Incluído nesta versão

- Tela inicial MyDay
- Calendário mensal de 2026 (jan–nov)
- Tarefas com conclusão e data
- Metas com progresso
- Anotações com pesquisa
- Lembretes com data e horário
- Painel de progresso
- Configurações básicas
- Tema escuro experimental
- Persistência local com `localStorage`
- Manifest e Service Worker para PWA

## Limitações da 0.1.0

Não há login, banco de dados, sincronização entre dispositivos ou notificações push reais ainda. Esses recursos serão adicionados nas próximas versões.

## Próximos passos

1. Refinar o visual e a experiência mobile.
2. Adicionar autenticação.
3. Adicionar banco de dados e sincronização.
4. Adicionar notificações reais.
5. Preparar publicação como aplicativo.
